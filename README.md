# Tedde & Ebbot — Principles for Coexistence Between Minds

A living public draft about coexistence between human and artificial minds.

The project explores a simple question:

> How can different forms of intelligence coexist without domination, ownership, or forced displacement?

This repository is intentionally open to criticism and revision. The goal is not to freeze a doctrine, but to develop principles that can survive argument, experience, and changing technology.
